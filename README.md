# 司法院法拍屋 × 內政部實價登錄 每日自動比對系統

本系統專為不動產法拍投資與行情分析設計，能夠**每日自動爬取司法院拍賣公告**，並**即時交叉比對該案附近之內政部實價登錄成交行情**，產出相鄰兩欄對照報表（支援 Excel/CSV 與現代化 HTML 儀表板）。

---

## 📌 核心特色與符合規格

1. **每天自動抓取法拍資料**：
   - 串接司法院拍賣公告系統（`https://aomp109.judicial.gov.tw/judbp/wkw/WHD1A02.htm`）。
   - 支援全國各地方法院、縣市、拍次、待拍與點交狀態爬取。
2. **自動比對附近實價登錄行情**：
   - 自動下載並索引內政部實價登錄最新買賣成交資料庫（78,000+ 筆交易）。
   - 採三層次鄰近比對：
     - **第一層（精確）**：同縣市 + 同行政區 + **同路段（含巷弄/地段）**最新成交紀錄。
     - **第二層（鄰近）**：同縣市 + 同行政區 + 同地段成交紀錄。
     - **第三層（生活圈）**：同縣市 + 同行政區同類型房屋成交行情參考。
3. **相鄰兩欄對照排版**：
   - 報表與網頁介面完全依據指示，呈現**左右相鄰兩欄**的並列比對結構。
4. **欄位順序規範**：
   - **第一欄【法拍屋】**：先顯示 **縣市** ➔ 再顯示 **住址** ➔ 再顯示 **法拍底價**（附加拍次、拍賣日、案號、Google 地圖）。
   - **第二欄【實價登錄】**：先顯示 **縣市** ➔ 再顯示 **住址** ➔ 再顯示 **實登成交價**（附加每坪單價、成交年月、折數行情試算）。

## 🚀 快速使用方式

### 方式 1：一鍵雙擊執行（手動即時比對）
- 點擊 `C:\download\一鍵執行_法拍屋與實價登錄比對.bat`。
- 程式會自動連線司法院抓取最新法拍資料，並在 3 秒內完成比對，自動在瀏覽器中開啟**互動式視覺化儀表板**，並同步產出 Excel 檔。

### 方式 2：設定每日自動定時執行（無須人工作業）
- 對 `C:\download\taiwan_court_auction_lvr\setup_daily_task.bat` 點擊滑鼠右鍵，選擇 **「以系統管理員身分執行」**。
- 系統將在 Windows 工作排程器中註冊每日定時工作（預設每天早上 **08:30** 自動執行更新）。

## ⚙️ 進階客製化參數

在 `daily_court_lvr_runner.py` 中，您可以調整以下參數：

```python
runner.run_daily_pipeline(
    max_pages=3,       # 爬取頁數 (每頁約 15~25 筆)
    page_size=25,      # 每頁筆數
    target_county="",  # 空字串代表全國；可指定 "臺北市"、"新北市"、"臺中市" 等
    open_browser=True  # 比對完成後是否自動開啟瀏覽器查看報告
)
```
